# lendas_do_CS

> Um site responsivo em HTML e Bootstrap dedicado às grandes lendas brasileiras do Counter-Strike.

## Visão geral

O **lendas_do_CS** é um projeto web estático que reúne páginas sobre jogadores brasileiros marcantes no cenário de Counter-Strike, como FalleN, coldzera, fer, fnx, TACO e KSCERATO. O site usa **HTML**, **CSS** e **Bootstrap** para estruturar navegação, carrosséis, páginas de trajetória, conquistas, premiações e dicas do jogo.[1] [2]

| Seção | Conteúdo |
|---|---|
| Página inicial | Apresentação geral e navegação para jogadores. |
| Jogadores | Páginas individuais com imagens e biografias. |
| Trajetória | Times, conquistas e premiações. |
| Dicas do jogo | Conteúdo para iniciantes e dicas avançadas em offcanvas. |
| Assets | Imagens, logo e arquivos HTML organizados em `p2 site responsivo`. |

## Estrutura do projeto

```text
p2 site responsivo/
   ├── index.html
   ├── fallen.html
   ├── coldezera.html
   ├── fer.html
   ├── fnx.html
   ├── taco.html
   ├── kscerato.html
   ├── dicas_do_jogo.html
   └── páginas de times, conquistas e premiações
```

## Como visualizar

```bash
git clone https://github.com/uliguimaraes/lendas_do_CS.git
cd lendas_do_CS/'p2 site responsivo'
```

Depois, abra o arquivo `index.html` no navegador. Por ser um projeto estático, não é necessário servidor para a visualização básica.

## Destaques criativos

O projeto funciona como uma espécie de galeria histórica: cada jogador tem sua própria rota visual, com imagens, navegação e páginas complementares. O uso de Bootstrap ajuda na responsividade e permite componentes como navbar, dropdown, carousel e offcanvas.[2]
